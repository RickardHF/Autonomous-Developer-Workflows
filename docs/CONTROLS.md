# McSquishy controls

The default keyboard controls are:

| Action | Keys |
| --- | --- |
| Move left | Left Arrow, `A` |
| Move right | Right Arrow, `D` |
| Jump | Up Arrow, `W`, Space |
| Pause | `P` |

Hold movement and jump keys to keep those actions active. Press `P` once to
pause and again to resume; releasing or holding `P` does not change the pause
state. Losing window focus clears held keys so movement cannot get stuck.
